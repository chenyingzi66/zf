# 图标资源说明

本目录用于存放小程序所需的图标资源。

## 需要的图标列表

### TabBar 图标
- home.png / home-active.png - 首页
- chat.png / chat-active.png - 沟通
- order.png / order-active.png - 订单
- profile.png / profile-active.png - 我的

### 功能图标
- search.png - 搜索
- filter.png - 筛选
- location.png - 位置
- view.png - 浏览
- arrow-down.png - 下拉箭头
- arrow-right.png - 右箭头
- wechat.png - 微信
- empty.png - 空状态
- phone.png - 电话
- message.png - 消息
- favorite.png / favorite-active.png - 收藏
- share.png - 分享
- back.png - 返回

## 图标规格
- TabBar 图标：81px × 81px
- 功能图标：根据实际使用场景调整

## 注意事项
1. 图标格式建议使用 PNG 格式
2. 图标背景透明
3. 图标颜色与设计规范保持一致
