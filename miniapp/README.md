# 随心住 - 住房租订系统微信小程序

## 项目简介

「随心住」是一款基于微信小程序原生开发的住房租订系统，支持**租客**与**房东**双角色完全隔离的业务流程，包含房源浏览、在线预定、消息沟通、订单管理等完整功能。

---

## 技术栈

- **前端**：微信小程序原生语法（WXML + WXSS + JS + JSON）
- **开发工具**：微信开发者工具 + VSCode
- **后端**：暂用本地模拟数据（Mock），完全适配后续 SpringBoot 后端对接

## 快速启动

1. 打开**微信开发者工具**
2. 选择「导入项目」→ 选择本项目根目录 `suixinzhu-miniapp/`
3. AppID 填写测试号或真实小程序 AppID（详见 `project.config.json`）
4. 点击「编译」即可预览运行

## 双角色权限说明

| 角色 | 入口 | 权限 |
|------|------|------|
| 租客 | 欢迎页 → 租客登录 → 租客首页 | 浏览房源、预定、收藏、订单、消息、投诉 |
| 房东 | 欢迎页 → 房东登录 → 房东中心 | 发布房源、管理订单、租客管理、数据统计 |

- **权限完全隔离**：租客无法访问房东页面，房东无法访问租客页面
- **未登录拦截**：所有业务页面均检查登录态，未登录自动跳转欢迎页
- **角色切换**：房东可一键切换回租客端（个人中心 → 切换至租客端）

## 模拟数据说明

当前使用本地 Mock 数据（`utils/mock.js`），切换为真实接口只需：

1. 修改 `utils/request.js` 第 6 行：`const USE_MOCK = false;`
2. 修改 `config/index.js` 中的 `apiBaseUrl` 为真实后端地址
3. 确保后端接口路径与各页面调用路径一致

## 接口规范（与后端对接标准）

### 统一响应格式

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {}
}
```

### 业务状态码

| 状态码 | 含义 |
|--------|------|
| 200 | 成功 |
| 400 | 参数错误 |
| 401 | 未授权 / Token 无效 |
| 403 | 权限不足 |
| 404 | 资源不存在 |
| 409 | 数据冲突（如日期冲突） |
| 500 | 服务器内部错误 |

```json
  "price": 3500,

  "area": 85,

  "images": ["url1", "url2"],
  "status": "online",
```

```json
{
  "id": "order_001",
```
